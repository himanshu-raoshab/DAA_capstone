Case A: Negative Edge Weight (No Cycle)

Greedy Dijkstra Fails

In EV green-corridor routing, edge C → B grants a -5 regenerative subsidy. Greedy Dijkstra settles B early at cost 4, missing the cheaper A → C → B path of cost 2.

Case B: Reachable Negative-Weight Cycle

Cycle Detected by Bellman-Ford

Adding B → C (+2) forms cycle B → C → B with total weight 2 + (-5) = -3 < 0. Bellman-Ford's |V|-th relaxation pass detects and isolates this cycle automatically.
